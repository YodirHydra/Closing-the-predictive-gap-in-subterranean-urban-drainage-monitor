# Jolodhar: supplementary data

Supplementary data for "Closing the predictive gap in subterranean urban drainage monitoring: an evidence analysis and a hydroclimate-coupled cyber-physical framework" (Research Team 7).

| File | Content |
|---|---|
| `supplementary_data_1_73_records.csv` | The 73 records (S1-S73) with coded capabilities (1 = present, 0 = absent; Type: IoT / Model / Review) |
| `supplementary_data_2_prisma2020.csv` | PRISMA 2020 selection summary; only the 73 retained studies are confirmed, other counts are not reported in the available records |
| `supplementary_note_1.md` | Literature search and study selection (information sources, inferred eligibility criteria, verification depth) |
| `source_matrix_73_papers.xlsx` | Source workbook (Sheet1: S1-S23; "New 50 Papers": S24-S73) |

IDs: S1-S23 are the rows of Sheet1 in order; S24-S73 are the rows of "New 50 Papers" in order.
